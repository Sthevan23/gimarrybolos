LIGAR / DESLIGAR O SITE GIMARRY
================================

O limite que derruba tudo é "Máximo de processos" (120), não disco.

DESLIGAR (libera processos)
---------------------------
Deixe o arquivo SITE_OFF na raiz (já no repo).
Com auto deploy + SITE_OFF: site/admin/API/fotos → offline.html

LIGAR DE NOVO
-------------
1. Apague SITE_OFF no GitHub ou no File Manager
2. Commit/push (se usar Git) ou só delete no servidor

NO PAINEL HOSTINGER
-------------------
- Em cada site: Ferramentas → "Parar processos" / liberar recursos (se aparecer)
- Sites que não usa: pause/exclua do plano
- Aurora com admin aberto também gera processo — não deixe painel aberto 24h
