# Gimarry Bolos — site estático

Só HTML/CSS/JS + fotos. Sem banco, sem API, sem painel.

## Estrutura

```text
index.html      → site
cart.html       → carrinho
style.css
script.js
js/data.js      → cardápio, textos, galeria
js/cart-*.js    → carrinho → WhatsApp
fotos_bolos/    → imagens
```

## Ver local

Abra `index.html` no navegador (ou Live Server na pasta do projeto).

Pedidos finalizam no WhatsApp. Cardápio e preços de fatias ficam em `js/data.js` e `script.js`.
